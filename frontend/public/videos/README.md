# Dashboard Video Background

## Required Video File

Place your dashboard background video here:
- **File name**: `dashboard.mp4`
- **Location**: `/public/videos/dashboard.mp4`
- **Recommended specs**:
  - Format: MP4 (H.264 codec)
  - Resolution: 1920x1080 or higher
  - Duration: 5-10 seconds (loops continuously)
  - File size: Keep under 10MB for good performance
  
## How to Add the Video

1. Create or find a farm/agriculture themed background video
2. Convert it to MP4 format if needed
3. Place the file in this directory as `dashboard.mp4`
4. The video will automatically play on the dashboard background

## Video Suggestions

Good video sources for farm background:
- Farm aerial views
- Green fields/crops
- Sunrise/sunset over fields
- Water droplets on crops
- Soil preparation animations

The video will loop continuously as a fixed background behind all dashboard content.
